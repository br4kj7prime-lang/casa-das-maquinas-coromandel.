Painel quase pronto

Falta ligar o site ao Supabase (banco de dados, login e fotos).

  1. Crie um projeto grátis em supabase.com.
  2. No SQL Editor, cole e rode o arquivo supabase-setup.sql.
  3. Em Authentication > Users, adicione o administrador (e-mail casadasmaquinas@casadasmaquinas.app, marcando "Auto Confirm User") e, em Sign In / Providers, desative "Allow new users to sign up".
  4. Em Project Settings > API, copie a URL e a chave anon public para o arquivo supabase-config.js e publique de novo no GitHub Pages.
